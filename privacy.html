隐私政策

适用于网站 pokedex-cn.netlify.app 以及 Windows / Android 离线版

简单说

本站没有账号系统，不收集姓名、手机号、邮箱等个人信息，没有广告，也没有接入任何统计或分析工具（如百度统计、Google Analytics）。我们没有自己的后端服务器，你的数据不会上传给我们。

保存在你设备上的数据

为了记住你的设置和进度，网站会把以下内容存在你浏览器（或 App）的本地存储 localStorage 里，键名都以 pkdx- 开头，只留在你自己的设备上：

  • 收藏、已捕获标记、筛选与排序偏好、上次选择的地区地图
  • 队伍构建器的队伍、对战小游戏的队伍与设置（pkdx-btTeam 等）
  • 小游戏的最高分和每日提示的显示状态
  • 更新公告是否已读；App 内更新检查的时间和“稍后提醒”的版本

会访问的第三方服务

  • Netlify：网站托管在 Netlify。和所有网站一样，访问时 Netlify 的服务器会按其政策处理 IP 地址、浏览器类型等访问日志，我们不额外读取或保存这些日志。详见 Netlify 隐私政策。
  • 图片与叫声备用源：图片和叫声大多已放在本站。个别本地缺失的文件，会从 jsDelivr（fastly / gcore / cdn.jsdelivr.net）或 raw.githubusercontent.com 加载 PokeAPI 的公开资源，这些服务会看到你的 IP 地址。
  • GitHub：下载页的安装包放在 GitHub Releases，从那里下载时由 GitHub 按其政策处理请求。
  • App 检查更新：离线版启动时会请求本站的 download/version.json，有新版并且你点“立即更新”后才会下载安装包。请求里不带任何身份信息。

App 权限

Android 版只申请两项权限：网络（检查更新和加载备用图片）和安装未知应用（只在你点“立即更新”时用于安装新版本）。不申请位置、相机、通讯录、存储等权限。Windows 版是普通的便携程序，不需要管理员权限。

如何清除数据

  • 网页：在浏览器设置里清除本站（pokedex-cn.netlify.app）的网站数据或 Cookie 与网站数据。
  • Android：设置 → 应用 → 宝可梦中文图鉴 → 存储 → 清除数据，或直接卸载。
  • Windows：删除程序文件，并删除 %APPDATA% 下以应用名命名的文件夹。

未成年人

本站不收集任何人的个人信息，未成年人也可以放心使用。

联系与变更
